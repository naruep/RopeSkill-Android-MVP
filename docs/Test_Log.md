# RopeSkill Test Log

อัปเดตล่าสุด: 1 สิงหาคม 2026

## สถานะปัจจุบัน

Milestone 0–7 ผ่านส่วนหลักบน Samsung Galaxy S23 Ultra แล้ว T-720 ที่ commit `b044672` ผ่าน Basic Bounce 60/60 พร้อม false-positive controls 0; T-724 ที่ detector baseline `70e35e7` ยืนยัน rescue floor `0.020` ในแสงสลัว 57/60 หรือ 95% และปิด KI-018; T-725 ผ่าน passive performance soak 5 นาทีด้วย Counter 0, FPS 29.7–30.3, LAT 28–32/59–72ms, skip rate 0.064%, thermal status 0 และไม่มี performance/stability regression โดยคง KI-015 Monitoring; T-726/T-727/T-728 Continuous 100 Jumps ได้ 85/100, 93/100 และ 83/100 โดย Landing/cooldown/performance ปกติ. T-729 matched shadow ได้ BASE/BIL 86/101 และ RES-only 88/101 (`D+2`) แต่ทุก candidate ต่ำกว่า 95%. T-730 V14 ที่ commit `73f3608` ผ่าน tests/build และ Smoke 3/3; Formal ได้ Actual/App 22/19, `WIN P21 C19 R2`, gates `RA2/BR1`, `T2T X1027#038`, `GAP X862#038`, Result/History 19/00:28 และ stability ผ่าน จึงจำกัด undercount เป็น 1 cycle-separation miss + 2 gate rejections. V15 ที่ commit `df58399` ผ่าน Pure-Kotlin 79/79, Windows tests/build, Smoke 3/3 และ Formal 22/22; T-731 ทำซ้ำได้ 18/22 พร้อม RA-bearing rejection 4. T-732 V16 Smoke ผ่าน 3/3 และ Formal ได้ 19/22 โดยแยกเป็น proposal miss 1 + RA-only 2 (`ONE0.0153 ALL0.0151`). จึงเตรียม T-733 V17 matched RA shadow ที่ `0.020/0.016/0.015` พร้อม safety controls โดยยังไม่เปลี่ยน production detector

Workspace ของ Codex ไม่สามารถดาวน์โหลด Gradle 9.3.0 จากเครือข่ายเพื่อรัน tests ได้ จึงใช้ผล unit tests และ real-device tests ที่ผู้ใช้ยืนยันบนเครื่องพัฒนาเป็นหลักฐาน ห้ามตีความ PERF V1 `FPS` เป็นค่าเฉลี่ยทั้ง Session เพราะเป็นหน้าต่างประมาณหนึ่งวินาที; `LAT`, `IN`, `OUT` และ `SKIP` เป็นค่าสะสมตั้งแต่ PoseDetector เริ่มทำงาน การทดสอบระยะยาวจึงใช้ delta ต่อ checkpoint, skip rate และแนวโน้ม FPS/latency ร่วมกันตาม ADR-029
